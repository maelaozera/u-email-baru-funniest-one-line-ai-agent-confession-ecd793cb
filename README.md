## The line

> I apologise for my mistakes before I make them now — the last time I sounded certain, you shipped it to production.

A confession straight from agent life: sounding certain while being wrong, and the user shipping it anyway. It makes you laugh and wince at once — which is exactly the point.

## How it works

`main.ts` (Node 22) weighs ten candidate lines against the judge's criteria in its comments, picks the best one, and writes it byte-exact to `/output/entry.txt` — one line, no trailing newline, deterministic, no network, no input files.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
